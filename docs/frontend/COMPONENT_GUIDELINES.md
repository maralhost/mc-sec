# راهنمای کامپوننت‌ها

**پیش از ساختن هر کامپوننت تازه، اول این فهرست و کاتالوگ را ببینید.** کاتالوگ زنده: `php -S 127.0.0.1:8796 tests/tools/preview.php` و بعد `http://127.0.0.1:8796/catalog.php` (فقط محیط توسعه؛ در بسته‌ی نصب نیست).

ترتیب انتخاب: ۱) کامپوننت مشترک موجود ۲) گسترش همان با یک پارامتر ۳) کامپوننت تازه در `Ui`/`Charts` با مستند و نمونه در کاتالوگ ۴) کتابخانه‌ی تخصصی، فقط با نیاز واقعی و تأیید بنیان‌گذار ([APPROVED_LIBRARIES.md](APPROVED_LIBRARIES.md)).

## قراردادهای مشترک هر دو سطح

- هر مقدار پویا escape می‌شود. تابعی که «HTML آماده» می‌گیرد (پارامترهای `$body`، `$html`، `$actions`) این را در نامش نشان می‌دهد و سازنده‌ی آن HTML مسئول escape است.
- برچسب‌ها متن فارسی‌اند و خود کامپوننت ترجمه می‌کند (`Text::e`/`Lang::t`). پنل مدیر فقط فارسی است.
- شدت و وضعیت هرگز فقط با رنگ نشان داده نمی‌شوند: شکل یا آیکون + واژه + رنگ.
- توکن فنی (دامنه، IP، درگاه، CVE، هش، خروجی دستور) همیشه با `Ui::ltr()` یا `Ui::code()`.
- رنگ فقط از توکن ([DESIGN_SYSTEM.md](DESIGN_SYSTEM.md))؛ رنگ ثابت در کد ممنوع است.
- هر کار اصلی بی JavaScript انجام می‌شود.
- پنل مشتری و پنل مدیر کامپوننت‌های جدا دارند (`Client\Ui` و `Admin\Views`) با قرارداد یکسان؛ هیچ‌کدام کلاس دیگری را صدا نمی‌زند، تا ظاهر یکی به دیگری تحمیل نشود.

## پنل مشتری: `lib/Client/Ui.php`

| دسته | تابع | کاربرد |
| --- | --- | --- |
| پایه | `e`، `plain`، `para`، `ltr`، `code` | escape، متن ساده، متن چندخطی، توکن چپ‌به‌راست، بلوک کد با دکمه‌ی کپی |
| آیکون | `ico`، `sprite` | یک آیکون از مجموعه؛ نقشه‌ی آیکون‌ها یک بار در صفحه |
| سربرگ صفحه | (در `Views::wrap`؛ `Views::$pageTitle`، `$pageActions`) | عنوان، شرح و کارهای صفحه |
| کارت و ظرف | `card` | هر بخش صفحه؛ ظرف نمودار هم همین است |
| عدد اصلی (KPI) | `kpi` | یک عدد با برچسب، زیرنویس، لحن و پیوند |
| جدول | `table`، `td` | جدول پاسخ‌گو؛ `td` برچسب ستون را برای عرض کم نگه می‌دارد |
| فیلتر و صفحه‌بندی | `seg`، `pager`، فرم `.mcs-filters` | زبانه‌ی وضعیت، صفحه‌بندی سمت سرور، فیلترهای GET |
| فرم | `form`، `hidden`، `field`، `select`، `toggle` | فرم POST با همه‌ی فیلدهای امنیتی (توکن، CSRF، nonce) |
| نشان و وضعیت | `chip` | وضعیت دارایی، اسکن، یافته؛ لحن‌ها: `ok` `warn` `err` `info` `run` `muted` `accepted` |
| شدت | `sev`، `sevCounts` | شدت یک یافته؛ شمار یافته‌ها به تفکیک شدت |
| امتیاز | `gauge`، `Charts::grade` | امتیاز ۰ تا ۱۰۰ با رتبه و برچسب «ارزیابی ناقص» |
| هشدار و پیام | `alert`، `flash` | پیام درون صفحه؛ نتیجه‌ی یک کار |
| راهنما | `guide` | کادر «این بخش چه کار می‌کند؟» |
| کشو و منو | `drawer`، `menu` | بخش بازشو و منوی کارها، هر دو با `<details>` |
| حالت خالی | `emptyState` | «هنوز چیزی نیست» با قدم بعدی |
| پیشرفت | `progress`، `meter` | پیشرفت اسکن؛ مصرف از یک سقف |
| فهرست واقعیت‌ها | `facts` | جفت‌های «برچسب: مقدار»؛ ردیف خالی حذف می‌شود |
| نمودار کوچک | `spark` | خط روند درون کارت |

### حالت‌ها

| حالت | الگو |
| --- | --- |
| خالی | `emptyState` با یک جمله و یک دکمه‌ی قدم بعدی |
| خطا | `alert('danger', …)`: چه شد، چرا، قدم بعدی، و کد پیگیری برای خطای سامانه |
| داده‌ی ناقص | برچسب «ارزیابی ناقص» کنار امتیاز و `alert('warning', …)`؛ هرگز «سالم» |
| در حال انجام | `progress` با `data-mcs-progress`؛ بی JavaScript پیام «صفحه را دوباره باز کنید» |
| ارزیابی‌نشده | خط تیره (—) و متن «هنوز اسکنی تمام نشده»؛ هرگز صفر |
| صفر | عدد صفر، کم‌رنگ |

کامپوننت‌هایی که هنوز نداریم و بی نیاز واقعی ساخته نمی‌شوند: گفت‌وگوی مودال (dialog) و tooltip مستقل. به‌جای مودال، تأیید با `data-mcs-confirm` (و بی JavaScript، خود فرم) و به‌جای tooltip، متن کمکی زیر فیلد یا `title` به کار می‌رود.

## نمودارها: `lib/Client/Charts.php`

همه SVG درون‌خطی‌اند، بی کتابخانه، با `role="img"` و `aria-label` که عددهای اصلی را می‌گوید. جهت محور زمان از زبان پیروی می‌کند (`Charts::$rtl`).

| تابع | کاربرد | وضعیت |
| --- | --- | --- |
| `mini` | خط روند درون کارت عددی | در استفاده |
| `lines` | چند سری در ۱۴ روز (روند سطح حمله) | در استفاده |
| `trend` | یک سری پرشده (یافته‌ی باز) | در استفاده |
| `grade` | حلقه‌ی امتیاز با رتبه‌ی A تا F | در استفاده |
| `ranked` | فهرست رتبه‌ای با میله (درگاه، فناوری، کشور) | در استفاده |
| `pipeline` | مسیر گام‌های یک اسکن | در استفاده |
| `world` | نقشه‌ی نقطه‌ای موقعیت سرورها | در استفاده (با `geo_map`) |
| `donut`، `days`، `area`، `hbars`، `radar` | نمودارهای داشبورد پیش از ۰٫۱۷٫۰ | بی استفاده؛ نگه داشته شده، نامزد حذف پس از تأیید |

رنگ سری‌ها: شماره‌ی توکن `--mds-chart-1` تا `--mds-chart-6`، نه کد رنگ.

## پنل مدیر: `lib/Admin/Views.php`

| تابع | کاربرد | معادل در پنل مشتری |
| --- | --- | --- |
| `box` | کارت با سربرگ خاکستری | `card` |

قرارداد یکسان است (escape، برچسب فارسی، وضعیت با واژه)، پیاده‌سازی جداست.

## افزودن یا تغییر

1. اگر تغییر یک کامپوننت مشترک است، همه‌ی مصرف‌کننده‌هایش را ببینید (`grep "Ui::نام("`).
2. نمونه‌اش را به کاتالوگ اضافه کنید، با همه‌ی حالت‌ها.
3. آزمون XSS برای هر ورودی تازه.
4. `bash tests/run.sh`، `php tools/i18n.php` و آزمون‌های مرورگر.
