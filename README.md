# MC-Sec — فضای کار امنیت سایبری مارال کلاد (WHMCS)

افزونه‌ی WHMCS 9 (PHP 8.3، قالب Lagom2) که به مشتری‌ها امکان می‌دهد همه‌ی نیاز امنیت سایت و سرورشان را در ناحیه‌ی کاربری انجام دهند:

- **دارایی‌ها:** دامنه، زیردامنه، فهرست صدتایی، IP و بازه‌ی کوچک IPv4، با **تأیید مالکیت** (DNS TXT، فایل، تگ متا، PTR؛ دامنه‌ها و IPهای سرویس‌های مارال خودکار).
- **اسکن:** بررسی سلامت پایه‌ی داخلی (TLS، هدرها، کوکی، SPF/DMARC، فایل‌های لورفته، درگاه‌های پرخطر)، کشف سطح حمله و اسکن آسیب‌پذیری با **OASM**، شناسایی و ارزیابی عمیق با **Osmedeus**؛ صف، سقف همزمانی، پیشرفت زنده.
- **یافته‌ها:** یکتا و با چرخه‌ی عمر (باز، رفع‌شده با اسکن بعدی، ریسک پذیرفته، مثبت کاذب)، امتیاز ۰ تا ۱۰۰، راه رفع فارسی با کد nginx/Apache/IIS/cPanel/وردپرس.
- **گزارش:** پایه‌ی رایگان پس از هر اسکن، **هوش مصنوعی** (هر سرویس سازگار با OpenAI) با خلاصه‌ی مدیریتی، ریسک‌ها، کارهای سریع، برنامه و راهکار هر یافته؛ چاپ/PDF؛ گزارش هفتگی/ماهانه.
- **زمان‌بندی و اعلان:** اسکن روزانه/هفتگی/ماهانه‌ی شمسی؛ خبر در پنل، ایمیل WHMCS، بله، تلگرام و وب‌هوک امضاشده.
- **اعتبار و قیمت:** کیف اعتبار (ماهانه‌ی رایگان گروه/پلن + خریداری‌شده)، بسته‌ها با فاکتور WHMCS، پلن‌ها به‌صورت محصول WHMCS با ماژول سرور `mcsecplan`.

## نصب
1. `php tools/release.php` ← `releases/mcsec-<نسخه>.zip`؛ محتوا را در ریشه‌ی WHMCS باز کنید (`modules/addons/mcsec` و `modules/servers/mcsecplan`).
2. Setup › Addon Modules › MC-Sec › Activate؛ Access Control برای نقش‌های مدیر.
3. Addons › MC-Sec › «راه‌اندازی موتورها»: OASM، Osmedeus، هوش مصنوعی و ربات‌ها؛ «آزمودن» هر کدام.
4. «تنظیمات»: روشن کردن برای چند حساب آزمایشی (`access_mode = list`)، بعد گروه‌ها یا همه.
5. (اختیاری) پلن‌ها: Setup › Products › محصول با ماژول «MC-Sec — پلن امنیت سایبری».
6. روی سرور: `php tools/selftest.php /path/to/whmcs`.

کار پس‌زمینه با cron خود WHMCS اجرا می‌شود (بی خط cron تازه).

## توسعه
- راهنما و قاعده‌ها: `CLAUDE.md`؛ طرح: `docs/DESIGN.md`؛ پژوهش‌ها: `docs/research/`؛ اسکیل‌ها: `.claude/skills/`.
- آزمون: `bash tests/run.sh` (SQLite، بدون شبکه).
- پیش‌نمایش: `php -S 127.0.0.1:8796 tests/tools/preview.php` ← `http://127.0.0.1:8796/index.php?m=mcsec` (حالت تیره `&dark=1`، پنل مدیر `/addonmodules.php?module=mcsec`).
