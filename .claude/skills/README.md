# اسکیل‌های MC-Sec

| اسکیل | کاربرد | منبع |
| --- | --- | --- |
| `mcsec-architect` | **طراح نرم‌افزار:** لایه‌ها، مدل داده، ADRها، چک‌لیست افزودن موتور/صفحه/جدول/مرحله‌ی کرون | نوشته‌شده برای MC-Sec |
| `mcsec-ideation` | **ایده‌پرداز نرم‌افزار امنیت سایبری:** فیلتر تطابق، امتیازدهی، الگوهای رقبا (`references/patterns.md`)، جریان‌ها (`flows.md`)، roadmap | نوشته‌شده برای MC-Sec، بر پایه‌ی `mcteam-ideation` |
| `cybersec-expert` | **کارشناس امنیت سایبری:** قواعد اسکن و دامنه، شدت و اولویت (CVSS/EPSS/KEV)، مثبت کاذب، OWASP/CWE، نوشتن راه رفع فارسی، امتیاز، نشانه‌ی نفوذ | نوشته‌شده برای MC-Sec |
| `mcsec-backends` | اتصال OASM و Osmedeus: احراز هویت، endpointها، جداسازی مشتری، دام‌ها، چک‌لیست اپراتور | نوشته‌شده برای MC-Sec (پژوهش در `docs/research/`) |
| `mcsec-ai-reports` | گزارش و پرامپت هوش مصنوعی، دفاع در برابر تزریق پرامپت، ماسک داده، کش، هزینه، ارزیابی | نوشته‌شده برای MC-Sec |
| `mcsec-billing-safety` | اعتبار، دفتر idempotent، بسته و فاکتور، پلن، قیمت، سوءاستفاده | نوشته‌شده برای MC-Sec، بر پایه‌ی `mcai-billing-safety` |
| `mcsec-rtl-review` | بازبینی رابط فارسی راست‌به‌چپ، توکن‌های LTR، حالت تیره، گوشی | کپی `mcteam-rtl-review` با نام‌ها و نمونه‌های MC-Sec |
| `whmcs-addon` | ساختن و تغییر ماژول WHMCS به روش پروژه‌های مارال | مشترک همه‌ی مخزن‌های مارال؛ همان md5 |
| `product-brainstorming`، `design-critique`، `ux-copy`، `accessibility-review` | طوفان فکری، نقد طرح، متن رابط، دسترس‌پذیری | Anthropic `knowledge-work-plugins` (`LICENSE-knowledge-work-plugins`) |
| `frontend-design`، `web-design-guidelines` | طرح دیداری و قاعده‌های عمومی وب | Anthropic skills / Vercel (مجوز در پوشه) |
| `dashboard-designer`، `information-architecture`، `form-design`، `ux-heuristics` | داشبورد، ساختار منو، فرم، بررسی کاربردپذیری | Claude-Cortex، designer-skills، wondelai (مجوزها کنار پوشه‌ها) |
| `prioritization-frameworks`، `opportunity-solution-tree` | اولویت‌بندی و درخت فرصت | pm-skills (`LICENSE-pm-skills`) |
| `pricing`، `onboarding`، `emails` | قیمت‌گذاری، شروع کار مشتری، ایمیل‌ها | marketingskills (`LICENSE-marketingskills`) |
| `audit-context-building`، `differential-review`، `fp-check`، `insecure-defaults`، `sharp-edges` | بازبینی امنیتی هر نسخه | Trail of Bits (`LICENSE-trailofbits-skills`) |

اسکیل‌های بیرونی از مخزن‌های دیگر مارال (MC-Team، MC-AI، MC-Care) کپی شده‌اند که پیش‌تر بررسی و pin شده بودند؛ از شبکه خوانده نمی‌شوند.
